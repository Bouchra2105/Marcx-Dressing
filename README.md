# Marcx-Dressing

Marcx-Dressing est un site web vitrine et catalogue pour une boutique de mode et vêtements/chaussures (streetwear, sapes, claquettes, t-shirts, survêtements, etc.).

## 📁 Structure du Projet

- `index.html` : Page d'accueil présentant les catégories populaires, sélections vedettes, et informations de contact rapide.
- `catalogue.html` : Page catalogue complète organisée par catégories avec filtres et recherche interactive.
- `a-propos.html` : Histoire, valeurs de la marque Marcx-Dressing et FAQ.
- `contact.html` : Formulaire de contact direct, coordonnées et lien WhatsApp.
- `style.css` : Feuille de styles principale responsive avec variables CSS.
- `script.js` : Logique client (navigation mobile, recherche, filtres du catalogue, animations).
- `images/` : Dossier contenant les assets graphiques et images des produits.
- `robots.txt` & `sitemap.xml` : Fichiers d'optimisation SEO.

## 🚀 Prévisualisation & Test Local

Ce projet est un site web statique HTML/CSS/JavaScript pur.

Vous pouvez le prévisualiser localement avec n'importe quel serveur HTTP statique, par exemple avec Python :

```bash
python3 -m http.server 8000
```

Puis ouvrez votre navigateur sur [http://localhost:8000](http://localhost:8000).

## ☁️ Déploiement (Render)

Ce site est hébergé sous forme de **Static Site** sur Render.

- **Publish Directory** : `./` (ou `.`)
- **Build Command** : Aucune (laisser vide)
- **Auto-Deploy** : Activé sur la branche principale (`main`)
